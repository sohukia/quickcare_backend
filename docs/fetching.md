# Fetching Feature

The `fetching` module provides utilities for retrieving data from various sources within the application. It is organized into submodules for different data providers.

## Modules

- **fetching.ORS**: Contains functions and classes for fetching data from the ORS (Open Routing Service) API.
- **fetching.PE**: Contains functions and classes for fetching data from the PE (Provider Endpoint) API.

## Usage

To use the fetching utilities, import the desired functions or classes from the `fetching` module:

```typescript
import { fetchORSData, fetchPEData } from '../src/fetching';
```

Refer to the documentation in each submodule for details on available functions and their usage.

## Exports

The following are re-exported from the `fetching` module:
- All exports from `fetching.ORS`
- All exports from `fetching.PE`
