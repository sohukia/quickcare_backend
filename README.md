# Quickare API Test

This project is a TypeScript-based Fastify API boilerplate.

## Features

- Fastify server
- TypeScript support
- Environment variable management with dotenv
- Linting with ESLint
- Testing with Jest

## Getting Started

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm run dev
```

### Build

```bash
pnpm run build
```

### Testing

```bash
pnpm test
```

## Configuration

Copy `.env.example` to `.env` and adjust environment variables as needed.

## Scripts

- `dev`: Start the development server
- `build`: Compile TypeScript to JavaScript
- `test`: Run tests with Jest
- `lint`: Run ESLint

## Folder Structure

- `src/` - Source code
- `dist/` - Compiled output
- `docs/` - Documentation
